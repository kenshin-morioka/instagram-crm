Instagram CRM

自分のInstagramリールに付いたコメントへ、公式APIを使って定型文を自動返信。
パソコンに常駐して、条件に合うコメントだけに返信します。

ダウンロード (macOS / Windows) 他のダウンロードオプション

無料・オープンソース（MIT License）

特徴

🔒

公式APIのみ使用

Meta公式のInstagram API (graph.instagram.com) だけを使用。スクレイピングや非公式API、ブラウザ自動操作は一切行いません。

🗝️

安全なトークン保管

アクセストークンはOS標準の保管領域（macOS: キーチェーン / Windows: 資格情報マネージャー）に保存します。

🧪

まずはドライランで確認

初期状態は返信を送らず、対象をログと履歴に記録するだけの「ドライラン」。実際の送信は「実送信を開始する」ボタンを押して初めて始まります。

🎯

返信対象を絞り込める

確認するリールの件数、何時間前までのコメントを対象にするか、1リールあたり何件まで確認するかを、アプリの画面から設定できます。

🔁

二重返信の防止

返信済みのコメントを記録し、同じコメントに二度返信しません。自分のコメントにも返信しません。

※ 記録するのはこのアプリの返信のみ。他のツールで返信したコメントは対象外です。

⏱️

API制限への配慮

レート制限（HTTP 429 やMetaのレート制限エラー）を検出するとRetry-Afterを尊重しつつ指数バックオフし、API使用量がしきい値（既定90%）を超えると送信を自動で一時停止します。

💻

クロスプラットフォーム

Windows、macOSに対応しています。

使い方

  1. アプリをインストール — 上のダウンロードボタンを押すと、お使いのOSに合ったインストーラー (macOS: .dmg / Windows: .msi) がダウンロードされます。
  2. Metaのアクセストークンを発行 — Instagramのプロアカウント（ビジネス/クリエイター）が必要です。手順は META_SETUP.md を参照してください。
  3. アプリと連携 — 発行したトークンをアプリに貼り付けて「連携する」を押します。
  4. 返信文を保存 — 自動返信で送る定型文を入力して保存します。未設定のままでは自動返信は動きません。
  5. ドライランで動作確認 — しばらく動かし、返信対象が意図どおりかログで確認します。
  6. 実送信を開始 — 確認できたら「実送信を開始する」ボタンを押して、実際の返信を始めます。

安全性について

  • 要求する権限はコメントの取得・返信に必要な2つのみ
    instagram_business_basic, instagram_business_manage_comments
  • トークンの実値・コメント本文・ユーザー名はログに出力しません
  • 送信をすぐ止めたいときは「送信を一時停止」ボタンで新規送信を停止できます
  • 第三者が参照できる静的レビュー（規約準拠の観点）の結果は COMPLIANCE_AUDIT.md で公開しています
