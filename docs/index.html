Instagram CRM

自分のInstagramリールに付いたコメントへ、公式APIを使って定型文を自動返信。
パソコンに常駐して、条件に合うコメントだけに返信します。

ダウンロード (macOS / Windows) GitHubで見る

無料・オープンソース（MIT License）。Linuxには対応していません。

特徴

公式APIのみ使用

Meta公式のInstagram API (graph.instagram.com) だけを使用。スクレイピングや非公式API、ブラウザ自動操作は一切行いません。

安全なトークン保管

アクセストークンはOS標準の保管領域（macOS: キーチェーン / Windows: 資格情報マネージャー）に保存します。

まずはドライランで確認

初期状態は返信せずログに出すだけの「ドライラン」。実際の送信を始めるには明示的にボタンを押す必要があります。

返信対象を絞り込める

対象リール・キーワード・コメントの取得期間・文字数などの条件で、返信対象を細かく設定できます。

二重返信の防止

一度返信したコメントは記録され、同じコメントに重複して返信することはありません。

API制限への配慮

レート制限（HTTP 429）に対して自動でバックオフし、使用量がしきい値を超えると自動的に一時停止します。

使い方

  1. アプリをインストール — 上のダウンロードボタンからReleasesページを開き、macOSは .dmg、Windowsは .msi を取得します。
  2. Metaのアクセストークンを発行 — Instagramのプロアカウント（ビジネス/クリエイター）が必要です。手順は META_SETUP.md を参照してください。
  3. アプリと連携 — 発行したトークンをアプリに貼り付けて「連携する」を押します。
  4. ドライランで動作確認 — しばらく動かし、返信対象が意図どおりかログで確認します。
  5. ドライランを解除 — 確認できたらボタンを押して、実際の返信を開始します。

安全性について

  • 要求する権限はコメントの取得・返信に必要な2つのみ（instagram_business_basic, instagram_business_manage_comments）
  • トークンの実値・コメント本文・ユーザー名はログに出力しません
  • 第三者が参照できる静的レビュー（規約準拠の観点）の結果は COMPLIANCE_AUDIT.md で公開しています
